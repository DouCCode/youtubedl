# CLI YT-DLP Bash Script

## Description

This repository contains a **bash script** that utilizes **yt-dlp** to download YouTube videos and audio. The script supports downloading from a single link, a playlist, or multiple links from a text file for bulk downloading. 

**Note:** This is a work in progress and should be considered a half-finished command-line interface (CLI) for yt-dlp.

## Features

- Download individual YouTube videos or audios  
- Download entire playlists
- Bulk download from a text file containing multiple video links
- Simple command-line interface

## Requirements

- **Bash**
- **yt-dlp**: Ensure yt-dlp is installed on your system. You can install it via:

  ```bash
  pip install -U yt-dlp
  ```

  or from your distro's official repository
## Usage

To use the script, follow these instructions:

1. Clone the repository:

   ```bash
   git clone https://github.com/220days/dylt-yt-dlp-tui.git
   cd dylt-yt-dlp-tui
   ```

2. Make the script executable:

   ```bash
   chmod +x dylt.sh
   ```

3. Download a video or audio:

  Just follow the instructions ad you'll be finished in no time.
